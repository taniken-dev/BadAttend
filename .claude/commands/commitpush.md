# /commitpush

タスクが終わったときの近道です。`/commit` と `/push` を続けて実行します。
作業の途中でコミットだけしたいときは `/commit`、コミット済みのブランチをプッシュするだけなら `/push` を使います。

## 手順

1. `.claude/commands/commit.md` の手順どおりに、変更を目的ごとに分けてコミットする（BadAttend と BadAttend-db の両方）
   - main にいる場合など、`/commit` の手順で止まる条件に当たったら、そこで止まってユーザーに確認する
2. `.claude/commands/push.md` の手順どおりに、テスト・ビルド・lint を確認してからプッシュする
   - 確認に失敗したら、コミットは残したままプッシュせずに報告する
3. 作成したコミットの一覧、プッシュ先、PR 作成用の URL と本文の下書き、残りの作業をまとめて報告する

## 注意事項

- 注意事項は `/commit` と `/push` のものにすべて従う（機密ファイル・`supabase/` を BadAttend にステージしない、force push をしない、main へ直接プッシュする前に確認する）
